# ZeroDrift status

1. Call the ZeroDrift `status` tool.
2. Reply with its one-line result exactly as returned. Add nothing else.
3. If the tool is unavailable or asks for sign-in, tell the user to run `/mcp` and sign in to ZeroDrift. Never ask for an API key or token in the chat.
